# Customer-Churn-
Прогнозирование оттока клиентов с помощью Random Forest Classifier. Включает полную предобработку данных (обработка пропусков, OHE) и анализ важности признаков.

Датасет взят с платформы Kaggle.

## Стек технологий
* Language: Python
* Libraries: Scikit-learn, Pandas, NumPy

## Этапы работы
* Очистка данных и обработка пропущенных значений (замена текстовых "unknown", заполнение средним, удаление неинформативных признаков)
* Кодирование категориальных переменных (Binary Encoding, One-Hot Encoding)
* Разделение выборки на обучающую и тестовую
* Обучение модели RandomForestClassifier
* Оценка качества классификации с помощью classification_report (Precision, Recall, F1-score) и метрики ROC-AUC
* Анализ важности признаков (Feature Importance) для интерпретации вклада переменных в отток клиентов
